Project 4 — Automate Everything: A Full CI/CD Pipeline

Built a GitHub Actions pipeline that takes a Flask app from commit to running on Kubernetes in about 6 minutes, against a 10-minute target. Each stage gates the next: flake8 lint, pytest with a 90% coverage gate, a multi-arch Docker build pushed to Docker Hub with versioned tags, and a deploy to a kind cluster through a self-hosted runner, finished with an in-cluster smoke test and a version audit trail. All credentials live in GitHub Actions Secrets; nothing is hardcoded.

Tools/Technologies Used: GitHub Actions · Python · Flask · pytest · flake8 · Docker · Docker Hub · Kubernetes · kind · Git/GitHub · VS Code / macOS

View Project

Project 5 — Production Monitoring with Prometheus & Grafana

Deployed a complete production monitoring stack on AWS (Prometheus for metrics collection, Grafana for dashboards and alerting, plus Amazon CloudWatch), provisioned with Terraform and full config-as-code. The server has no inbound SSH; all access goes through AWS Systems Manager Session Manager. Alerts are delivered as real email over SMTP, and each one is backed by a written runbook.

Tools/Technologies Used: Terraform · Amazon EC2 · AWS Systems Manager · Prometheus · Grafana · Amazon CloudWatch · Git/GitHub · VS Code / macOS

View Project

Project 6 — Job Application Assistant & Tracker

A local-first job search assistant that pulls listings from public Greenhouse and Lever APIs, uses the Anthropic Claude API to tailor resume bullets to each posting, and tracks my application pipeline in a SQLite database with a Streamlit view on localhost. It's human-in-the-loop by design: it prepares, and I review and submit, with no auto-apply and no scraping. I delivered it as a six-ticket epic, each ticket on its own branch and pull request, with secrets and personal data kept out of the repo.

Tools/Technologies Used: Python · Anthropic Claude API · Greenhouse & Lever APIs · SQLite · Streamlit · Git/GitHub · VS Code / macOS
